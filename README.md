## 🎨 Design Approach

The website uses an off-white background, dark text, and muted green accents to create a calm and professional appearance.

The layout focuses on readability, clear spacing, and simple interactions rather than excessive animations or visual effects.

## 📱 Responsive Design

CSS media queries adjust the layout for smaller screens. The project cards, navigation, and content sections adapt to different screen sizes.

## 🌍 Deployment

This website can be hosted for free using GitHub Pages.

1. Push the project files to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under the build and deployment settings, choose **Deploy from a branch**.
5. Select the `main` branch and the `/(root)` folder.
6. Save and wait for the website to be published.
7. Copy the published URL into the Live Preview section above.

Deployment instructions: [GitHub Pages Documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)
